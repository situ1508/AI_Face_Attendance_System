# 🎓 AI Face Recognition Attendance System

An AI-powered Face Recognition Attendance System built using Python, OpenCV, Flask, and SQLite. The system automatically recognizes registered students through facial recognition and marks their attendance in real time.

---

## 📌 Features

- 🔐 Admin Login
- 👨‍🎓 Student Management
- 📷 Face Capture using Webcam
- 🧠 Face Recognition using LBPH Algorithm
- ✅ Automatic Attendance Marking
- 📅 Date-wise Attendance Records
- 📊 Attendance Reports Dashboard
- 📈 Attendance Statistics
- 💾 SQLite Database Integration
- 🌐 Flask Web Interface

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/situ1508/AI_Face_Attendance_System.git
```

### Open Project

```bash
cd AI_Face_Attendance_System
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python app.py
```

## 🧠 Working

1. Register Student
2. Capture Face Images
3. Train Face Recognition Model
4. Start Attendance
5. Face is Recognized
6. Attendance is Automatically Stored in SQLite Database
7. Reports are Generated
